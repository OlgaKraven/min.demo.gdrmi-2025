# Korochki.есть — Демоэкзамен ГДРМИ БУ

## Запуск

1. pip install flask flask-cors pymysql
2. Импортировать db/korochki.sql в phpMyAdmin
3. python backend/app.py
4. Открыть http://127.0.0.1:5000/login
