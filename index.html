    Подготовка к демоэкзамену ГДРМИ

    Внимание

    Это НЕ эталонный пример. Проект создан для подготовки к демоэкзамену по специальности 09.02.07 «Информационные системы и программирование», направление «Разработчик веб и мультимедийных приложений», базовый уровень (БУ).

    Код намеренно минимален. Все задания рассмотрены на основе официального задания 2026 года.

    Официальные данные

    • Время проведения: 3 часа 00 минут
    • Проходной балл: 40 из 75
    • Официальная документация: http://bom.firpo.ru/Public/5508

    👉 Скачать приложение М1 · Скачать приложение М2

    Стек технологий

    Категория Программное обеспечение
    Окружение XAMPP (Apache + MySQL + PHP + FTP)
    Редактор VS Code
    Браузеры Google Chrome, Mozilla Firefox
    Графика GIMP, Inkscape
    Прототипирование Figma (веб)
    API Postman
    Среда выполнения Node.js, Python
    VCS Git
    Фреймворки Bootstrap, Vue.js, React (через npm), Laravel (через Composer), Flask/Django (через pip)

    Распределение баллов

    № Вид деятельности Критерий Баллы
    1 Модуль 1. Разработка ИС Безопасность, модули ИС, поиск информации 25,00
    2 Модуль 2. Дизайн веб-приложений Дизайн-концепция, требования, разработка дизайна 25,00
    3 Модуль 3 (ПУ) Разработка и оптимизация веб-приложений 25,00
    ИТОГО 75,00

    Базовый уровень (БУ)

    Для базового уровня выполняются только Модуль 1 и Модуль 2. Модуль 3 — только для повышенного уровня (ПУ).

    Схема оценивания

    Баллы Критерий
    2 Действие выполнено в полной мере
    1 Действие выполнено, но с незначительными ошибками
    0 Действие не выполнено
